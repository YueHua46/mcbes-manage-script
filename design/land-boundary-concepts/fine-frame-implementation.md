# 领地流动光幕结界

## 视觉与运行时契约

- 主体是四个侧面上的世界固定透明光幕，带几何格纹、流动丝线和向上扫过的光波。准确三维外表面的细线承担封边。包含式方块端点的最大外表面始终为 `max + 1`。
- 光幕以四格见方的稳定面片拼接；不足四格的末端通过尺寸与 UV 同时裁剪，不拉伸图案。128×2048 的十六帧纹理由客户端 UV 每秒八帧播放，刷新时使用统一相位。
- 底边叠加不超过 0.85 格高的渐变能量带；转角采用交叉的加法混合光脊。两者均停在领地真实上下界内。幕面优先获得预算，顶部不铺透明盖面。
- 每条边按四格分段，每段两个互相垂直的世界固定面片；横向纹理不淡化端点，避免接缝变成虚线。
- 八个角点使用小菱形；符文使用中性透明纹理，在世界固定的竖直面上稀疏排列。单格领地没有符文。
- 自有领地青蓝、可信成员绿、公会金、公开灰蓝、其他领地橙。这些颜色表示关系，不代表所有具体操作权限。
- 常显底边、竖边、顶边分别使用 0.60、0.45、0.30 强度，并在显示距离外侧四分之一区间衰减。
- 进入/离开和主动查看使用短暂强化的同一轮廓；不再叠加大型地面法阵或立柱。
- 圈地预览继承现有有效/警告/冲突颜色，粒子寿命 1.15 秒，配合原有每 20 tick 更新。DebugUtilities 可用时，现有带标签的调试预览继续工作。
- 平衡/高档每个领地最多一个流光，以四格/秒在真实顶面或底面周长上移动。位置在粒子 Molang 中逐帧计算，脚本不再每四 tick 生成静止波头。低档不显示流光。

## 预算与刷新

| 档位 | 轮廓距离 | 光幕距离 | 单领地面片上限 | 单领地线段上限 | 最近领地数量 | 每玩家每轮常显发射预算 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 低 | 48 | 24 | 48 | 96 | 3 | 360 |
| 平衡 | 80 | 40 | 96 | 192 | 4 | 720 |
| 高 | 112 | 56 | 144 | 288 | 6 | 1080 |

一段线消耗两个粒子，一个光幕面片或能量带消耗一个粒子。多个领地的 job 共享同一个预算对象；角点、符文、流光也计入预算。光幕在显示范围外侧八格内渐隐。
每 40 tick 更新，寿命 2.15 秒，首尾各 0.15 秒渐变。菜单、常显和进出事件的相同几何在同一租期内去重。
选择预览和事件提示各自受单次预算限制；表中总预算特指一轮附近领地常显，不包含其他游戏粒子。

线段先与玩家周围球形范围相交再采样，不遍历巨大领地整条边。超预算优先近处线段。
分片任务在玩家失效、切换维度或请求超过 20 tick 后停止，不在新维度补画旧边框。
已发出的粒子依靠短寿命自行消失；API 没有提供此处可用的粒子删除句柄。

## 文件与资源重建

- `scripts/features/land/services/land-boundary-frame.ts`：裁剪、线段预算和流光路径。
- `scripts/features/land/services/land-boundary-render-plan.ts`：三维范围、十二条边和稀疏符文规划。
- `scripts/features/land/services/land-particle.ts`：个人可见粒子、分片、状态颜色和重复请求去重。
- `scripts/events/handlers/land.ts`：常显调度及共享预算。
- `tools/generate-land-boundary-frame.cjs`：确定性生成七张中性遮罩/动画纹理和十六份 `ward_*` 粒子定义。

```powershell
node tools/generate-land-boundary-frame.cjs
npm run typecheck
node --test tests/land-boundary-*.test.cjs
npm test
npx just-scripts package:standard
```

历史 `land_boundary_*` 素材保留，新的常显渲染器不再引用；旧素材生成器不会覆盖 `ward_*` 资源。
本实现不修改 JSON UI 路由或保护/权限逻辑。

## 实机验收边界

自动化验证覆盖几何连续性、单格/反向端点/超大范围、资源尺寸、客户端流光表达式、共享预算、重复请求、切换维度和分片过期。
这些测试不等于 Bedrock 引擎画面验收。需在游戏内检查：

1. 同一村庄白天、夜晚，第一/第三人称与俯视、侧视的线宽和接缝。
2. 在 X/Y/Z 三方向观察交叉面片，确认没有随镜头旋转或整段消失。
3. 连续观察多个刷新周期，检查透明交接是否有可见闪亮/断线。
4. 单格、坡地、地下和巨大领地仅显示实际三维边缘，不把地表或玩家高度误当成上下界。
5. 多领地和低性能客户端的 FPS、内容日志，以及切维度/关闭显示后粒子的自然消退。

本阶段包含附近四个侧面的流动光幕，不包含自动贴地线、环境光照或折射。距离之外以及预算不足的几何会被裁剪；不保证从远处完整看到巨大领地。引擎内的透明排序、白天对比度和实际 FPS 仍需实机验收。
