# CreeperMenu 治愈系像素 JSON UI

这一版采用低饱和、暖色、场景化的像素卡片风格。它借鉴 DogeUI 轻松的视觉节奏与卡片拼图信息架构，但不复用其角色、服务器品牌、布局或素材。所有功能场景图、按钮状态和布局均为苦力怕菜单单独设计。

不同 SAPI 表单如何互斥选择拼图、纵向或原生界面，详见 [`JSON_UI_ROUTING.md`](JSON_UI_ROUTING.md)。这是运行时契约；修改 `server_form.json`、`creeper_menu.json` 或 ActionForm 标题包装逻辑前必须先阅读。

## 视觉与交互约束

- 左侧为 3/2/3 紧密功能拼图，右侧为任务主视觉、菜单道具横幅和三个快捷入口组成的 1/1/3 纵向拼图。
- 13 个卡片索引与 `scripts/ui/forms/server/index.ts` 保持固定契约；关闭的模块和无权限入口保留空槽，不会导致后续按钮错位。
- 根菜单的每个按钮都是按最终槽位比例绘制的独立像素海报，固定标题直接烘焙进状态纹理，保证不同 GUI 缩放下的描边、留白和构图一致。
- 根菜单默认、悬停、按下均有独立全图纹理和烘焙边框；不得为这些纹理附加九宫格元数据，否则场景会被拆开拉伸。鼠标、触屏和手柄共用同一点击映射。
- 苦力怕主菜单使用 `/CMROOT` 拼图布局；项目内 ActionForm 通过 `/CMFORM` 使用统一的暖色纸张卡片布局。
- 箱子、熔炉、JavaScript REPL 与其他附加包表单保留各自原有路由，避免资源包全局误接管。

## 视觉系统

- 根菜单取消大面积外框和品牌页眉，只保留左上标题、右上关闭按钮与紧密拼图，让游戏世界成为自然背景。
- 卡片以奶油黄、鼠尾草绿、天空蓝、灰紫和浅珊瑚为主，避免荧光绿和科技终端感。
- 卡片改用低像素密度、粗轮廓、少层次的插画语言，并用透明圆角遮罩统一软化拼图边缘；标题位于专门留出的浅色安全区，任务卡使用底部标题带。
- 通用子菜单使用单层暖色圆角面板、紧凑圆角按钮、统一图标底托和右侧方向提示，不再套叠多层粗黑边框。
- 苦力怕仅作为菜单书吉祥物和品牌识别，不再作为整屏荧光绿色主题。

## 素材来源与重建

- `source/creeper-feature-atlas-cozy-imagegen.png`：使用内置 ImageGen 生成的 4×4 原创治愈系像素素材母版。
- `source/creeper-mosaic-left-323-imagegen.png`：按 3/2/3 最终拼图比例生成的左侧原创像素海报母版。
- `source/creeper-mosaic-right-113-imagegen.png`：按 1/1/3 最终拼图比例生成的右侧原创像素海报母版。
- `build.py`：透明图标仍按连通主体切分；根菜单海报则按固定槽位裁切、烘焙标题和交互边框，同时生成通用按钮九宫格与两张预览图。
- `preview.png` / `submenu-preview.png`：主菜单拼图和通用子菜单的设计预览。

python design/menu-ui/build.py
