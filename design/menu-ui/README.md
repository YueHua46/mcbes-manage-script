# CreeperMenu 治愈系像素 JSON UI

这一版采用低饱和、暖色、场景化的像素卡片风格。它借鉴 DogeUI 轻松的视觉节奏与卡片拼图信息架构，但不复用其角色、服务器品牌、布局或素材。所有功能场景图、按钮状态和布局均为苦力怕菜单单独设计。

不同 SAPI 表单如何互斥选择拼图、纵向或原生界面，详见 [`JSON_UI_ROUTING.md`](JSON_UI_ROUTING.md)。这是运行时契约；修改 `server_form.json`、`creeper_menu.json` 或 ActionForm 标题包装逻辑前必须先阅读。

## 视觉与交互约束

- 左侧为 3/2/3 紧密功能拼图，右侧为任务主视觉、菜单道具横幅和三个快捷入口组成的 1/1/3 纵向拼图。
- 13 个卡片索引与 `scripts/ui/forms/server/index.ts` 保持固定契约；关闭的模块和无权限入口保留固定槽位，不会导致后续按钮错位。
- 根菜单的每个按钮都是按最终槽位比例绘制的独立像素海报，固定标题直接烘焙进状态纹理，保证不同 GUI 缩放下的描边、留白和构图一致。
- 根菜单以 920×510 为设计画布，通过两层 `max_size` 按 920:510 等比收进当前安全画布：窄屏按宽度缩放，超宽屏按高度缩放。不得再用两个互不关联的屏幕百分比分别拉伸画布，也不得给根画布设置会撑出安全区的 `min_size`。
- 关闭模块或无权限入口仍保留固定 collection 索引，但以灰度 locked 卡片占位并禁用点击，不再留下会透出 HUD 的透明空槽。
- 根菜单默认、悬停、按下均有独立全图纹理和烘焙边框；悬停整体下移 1px，按下下移 2px。卡片状态必须关闭 `keep_ratio`，否则任务卡、横幅卡和正方形快捷卡会按各自原图比例向内缩，无法共享同一左右边线。不得为这些纹理附加九宫格元数据，否则场景会被拆开拉伸。鼠标、触屏和手柄共用同一点击映射。
- 苦力怕主菜单使用 `/CMROOT` 拼图布局；项目内 ActionForm 通过 `/CMFORM` 使用“像素冒险手册”纵向目录。森林绿书脊页眉、奶油纸张内容页、黄铜描边和原创书本徽记共同承担层级，不再依赖一整块空白大面板。
- 项目内 MessageForm 通过 `/CMMESSAGE` 使用同一套冒险手册双按钮消息页；正文拥有独立纸张滚动区，两个原生选择索引固定映射到左右按钮，并用地图与指南针徽记明确“消息 / 确认”语境。
- 项目内 ModalForm 通过 `/CMMODAL` 使用同一套冒险手册设置页，并为下拉框、开关、连续/步进滑块、文本框、标签、分隔线与深绿主操作按钮提供完整主题控件；底层仍保留原生输入、焦点和提交绑定。
- 任务系统 HUD 提示使用独立的羊皮纸委托票据：左侧稀有度色条承担颜色编码，徽章底托容纳 158 个任务图标，找不到专属图标时回退到原创星章任务徽记；普通、稀有、史诗、传说只改变语义色和标签，不再逐级堆叠角饰。
- 箱子、熔炉、JavaScript REPL 与其他附加包表单保留各自原有路由，避免资源包全局误接管。

## 视觉系统

- 根菜单取消大面积外框和品牌页眉，只保留左上标题、右上关闭按钮与紧密拼图，让游戏世界成为自然背景。
- 卡片以奶油黄、鼠尾草绿、天空蓝、灰紫和浅珊瑚为主，避免荧光绿和科技终端感。
- 卡片改用低像素密度、粗轮廓、少层次的插画语言，并用透明圆角遮罩统一软化拼图边缘；标题位于专门留出的浅色安全区，任务卡使用底部标题带。
- 通用子菜单采用两层“书封 + 内页”结构：不透明暖灰封面包裹奶油纸张内容页，56px 森林绿页眉固定展示表单标题、场景副标题和 43px 原创徽记。桌面端使用较窄较高的 `48% × 76%` 阅读比例，触屏使用 `76% × 86%`，并限制在 560×420 安全尺寸内。
- ActionForm 条目占用 39px 行高、卡片本体高 36px，左侧独立的 3×28px 圆头绿色索引条、统一图标底托、主次文字和右侧方向提示形成稳定的扫描路径。单行标题按卡片光学中心布局，两行标题/说明整体向上补偿字体基线；滚动面板填满内容框，列表内容左右各保留 6px 逻辑内边距，2px 原生滚动条贴近右边，避免右侧出现大块空白或卡片贴住滑块。按钮直接继承 `common.button` 并由一套完整状态纹理绘制，禁止再套用会额外绘制深色轮廓的 `common_buttons.light_text_button`。“返回 / 关闭 / 上一页”仍可复用通用导航图标，但识别到返回图标时必须隐藏右向箭头，避免同一行同时表达相反方向。
- 关闭按钮是一个完整的自定义状态按钮，不得在原生关闭按钮外继续叠加装饰框。路由包装器只会移除路由标题里的原生格式色；正文、字段值、选项和按钮文字保留业务层的颜色语义，但统一映射为适合奶油纸张背景的深色墨水调色板：下界合金色用于正文、深灰用于次要信息、铜色用于强调、青金石色用于信息、红石色用于危险，并保留克制的深绿和深紫。
- 苦力怕仅作为菜单书吉祥物和品牌识别，不再作为整屏荧光绿色主题。

## 素材来源与重建

- `source/creeper-feature-atlas-cozy-imagegen.png`：使用内置 ImageGen 生成的 4×4 原创治愈系像素素材母版。
- `source/creeper-mosaic-left-323-imagegen.png`：按 3/2/3 最终拼图比例生成的左侧原创像素海报母版。
- `source/creeper-mosaic-right-113-imagegen.png`：按 1/1/3 最终拼图比例生成的右侧原创像素海报母版。
- `source/creeper-submenu-icons-core-imagegen.png`：坐标点、假人、公会、死亡返回、维度与传送等核心子菜单的 4×4 原创图标母版。
- `source/creeper-submenu-icons-admin-imagegen.png`：黑白名单、成员权限、背包、市场、公告与状态等管理子菜单的 4×4 原创图标母版。
- `source/creeper-submenu-emblems-imagegen.png`：使用内置 ImageGen 生成的 2×2 透明徽记母版，分别输出 ActionForm、MessageForm、ModalForm 与任务提示的共享场景徽记。
- `assets/quest-icons-atlas-b01-v2.png` 与 `assets/quest-icons-atlas-b02-v1.png` 至 `b10-v1.png`：158 个预设任务图标的原始 ImageGen 色键母版。生成器画面允许跨越名义网格，但每个主体必须靠近自己的 4×4 预期中心。
- `quest-icon-manifest.json`：任务 ID、稳定 slug、母版格位、不可见 HUD marker 索引、连通域策略与光学偏移的唯一事实源。
- `build.py`：透明图标仍按连通主体切分；两张子菜单图标母版按固定 4×4 单元切分并清除微小游离像素，输出原生 32×32 RGBA；2×2 场景徽记母版输出四张 64×64 RGBA；根菜单海报按固定槽位裁切、烘焙标题和交互边框，同时生成完整的冒险手册九宫格纹理与预览图。
- `preview.png` / `submenu-preview.png` / `modal-preview.png` / `message-preview.png` / `quest-toast-preview.png` / `quest-icons-preview.png`：主菜单拼图、通用子菜单、完整 ModalForm 控件、双按钮 MessageForm、四级任务票据与任务图标的设计预览。

子菜单图标以“一个业务概念对应一个清晰轮廓”为准。返回、确认、删除、翻页等通用动作可以复用；公会列表/我的公会、自杀/死亡地点返回、私人/公共坐标点等会改变用户判断的业务入口必须使用不同图标。

```powershell
python design/menu-ui/build.py

# 原始 ImageGen 母版先按完整连通主体归组，重排为带安全区的标准 4×4 母版。
python design/menu-ui/build.py --normalize-quest-atlases

# 从标准母版输出 158 个 32px PNG，并同步生成 TS 映射与 HUD badge controls。
python design/menu-ui/build.py --quest-icons
```
