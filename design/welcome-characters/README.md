# 像素角色进服欢迎素材

玩家首次进入时会从 `scripts/assets/glyph-map.ts` 的 `welcomeCharacterGlyphs` 中随机选择一个角色，
并通过 `titleraw subtitle` 播放原有淡入、停留和淡出动画。

每个字形槽为 60×60。运行时保留角色原稿约 49–55 像素的可见高度，并在角色与欢迎装饰之间

## 素材目录

- `source/`：内置图像生成工具输出的纯色抠图底原稿。
- `final/`：使用 imagegen 技能的 `remove_chroma_key.py` 去底后的透明高清 PNG。
- `glyphs/`：以最近邻缩放得到的 60×60 运行时字形。

## 生成提示词方向

全部图片均以对应旧版假人 64×64 皮肤为身份和配色参考，要求：单个全身 Q 版角色、挥手欢迎、
16-bit 手绘像素风、方形构图、缩至 60×60 后仍有清晰轮廓、少量贴近人物的主题色像素闪光、
无文字、无水印、无投影。绿色系角色使用纯洋红抠图底，其余角色使用纯绿色抠图底。

洛琪希的重绘版本以动画经典魔术师造型校正：蓝色双辫、棕色宽檐帽、棕色短斗篷、白色上衣、
深色短裙和白靴，避免误画成长蓝袍。长门有希的重绘版本使用低饱和浅灰紫发色，并保留红框眼镜
与北高校服。两张新版抠图底原稿分别为 `source/roxy-v2-chroma.png` 和
`source/yuki_nagato-v2-chroma.png`。

艾莉丝的重绘版本使用动画第一季经典造型：长红发、黑色发箍、粗眉红眼、白色露肩蓬袖上衣、
黑色饰边与深色裙装，移除了旧图中不属于该造型的红黑战甲和复杂腰带。新版抠图底原稿为
`source/eris_greyrat-v2-chroma.png`。

以后增加角色时，把带透明留白的正方形成品缩放到 60×60 空槽，并在
`welcomeCharacterGlyphs` 末尾加入对应的 `U+E8xx` 字符即可进入随机池。
