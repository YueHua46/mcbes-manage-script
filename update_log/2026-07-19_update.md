# 更新说明 · 2026-07-19

> 更新版本：3.1.0

## 进服欢迎与菜单视觉更新

进服欢迎画面改为随机展示 16 套二次元像素角色，并移除了动画后的黑色背景，重新调整了角色、欢迎文字的间距和垂直位置。

主菜单及各级功能菜单统一换用更清晰的像素图标，按钮图案会更贴合对应功能。

本次更新包含资源包改动，更新后需要同时替换行为包和资源包，并重新进入世界。

## 新版假人改为生存玩法

新版模拟玩家现在以生存模式运行，可以被敌对生物攻击。死亡后会保留死亡原因和最后位置，不再自动复活；玩家可在假人详情中手动复活。

操作入口：`玩家操作 -> 假人管理 -> 我的假人列表 -> 选择已死亡的新版假人 -> 复活假人`。

管理员可在 `服务器设置 -> 通用系统设置 -> 新版假人复活费用` 中修改费用，设置为 0 即可免费复活。持续挖掘也已优化，假人会连续挖掘当前看向的方块，无需手动填写方块坐标。

## 领地保护与圈地操作优化

新增活塞跨领地边界保护，防止玩家在领地外放置活塞，隔着边界推动、拉取或顶碎领地内的方块。

圈地过程中会持续显示取消方法。如需退出圈地状态，请潜行并手持木棍长按空气，不要对着方块。

管理员还可以关闭普通玩家的领地传送功能。关闭后，普通玩家将看不到传送和传送点设置入口，已有传送点不会被删除，管理员仍可使用。

操作入口：`服务器设置 -> 领地系统管理 -> 领地传送设置`。

## 行为日志追踪与名称显示优化

新增“领地活塞破坏尝试”危险行为日志。越界活塞触发保护时，会记录发生时间、坐标、领地、活塞类型，以及近期可能触发该活塞的玩家操作。

## 经济系统关闭后的显示统一

关闭经济系统后，右上角状态栏只保留 TPS 和在线人数，不再显示金币；财富排行榜、PVP 夺金统计和相关金币提示也会自动隐藏。

传送、假人和悬浮文字等原本需要金币的操作会按免费处理。任务中的金币奖励会跳过，不会再导致整个任务领取失败。

## 数据保存稳定性优化

数据库自动保存改为分批错峰执行，减少多个大型数据同时保存造成的瞬间卡顿；保存失败时也会延迟重试，避免持续影响服务器运行。
