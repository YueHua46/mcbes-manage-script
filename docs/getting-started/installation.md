# 安装与首次启动

## 安装前

1. 备份世界目录和服务器配置。
2. 根据运行环境选择正确构建变体。
3. 确认 Minecraft Bedrock 版本与项目兼容矩阵一致。

## 普通兼容版

适用于本地世界、Realms 和 BDS。

1. 下载文件名包含 `standard` 的 `.mcaddon`。
2. 本地世界可直接导入；服务器请将行为包和资源包放入对应目录。
3. 在世界中同时启用行为包与资源包。
4. 完整退出并重新启动世界或服务器，不要只执行 `/reload`。

## BDS 增强版

仅适用于支持 `@minecraft/server-admin` 与 `@minecraft/server-net` 的 BDS。

1. 下载文件名包含 `bds` 的 `.mcaddon`。
2. 部署行为包和资源包。
3. 确认 BDS 环境允许使用所需模块和网络能力。
4. 完整重启服务器。

## 首次验证

启动后检查控制台是否出现“所有模块已加载成功”，再进入游戏验证管理菜单、基础传送和数据保存。生产服启用经济、领地、公会等模块前，建议先在副本世界完成测试。
