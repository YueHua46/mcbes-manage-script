# 兼容性说明

## 当前目标版本

- 苦力怕菜单：v3.0.1
- Minecraft Bedrock：1.26.x
- `min_engine_version`：`[1, 26, 0]`

## 运行环境

| 环境 | 普通兼容版 | BDS 增强版 |
|---|:---:|:---:|
| 本地世界 | 支持 | 不支持 |
| Realms | 支持 | 不支持 |
| BDS | 支持 | 支持 |

## 已知限制

- Preview/Beta Script API 可能随 Minecraft 更新发生破坏性变化。
- 普通兼容版无法使用进服前黑名单拦截、HTTP 出站和 XUID 解析。
- 自定义维度首次安装或升级后需要完整重启。
- 多个 Addon 修改相同 UI、资源路径、动态属性或事件行为时可能发生冲突。

提交兼容性问题时，请提供 Minecraft 精确版本、运行环境、构建变体、其他已启用 Addon 和完整日志。
