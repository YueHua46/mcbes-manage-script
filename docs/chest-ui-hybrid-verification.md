# Chest UI 实验失败与恢复（v3.3.4）

v3.3.3 游戏验证失败：数字原生图标大面积不显示，数量和悬停说明仍存在；贴图路径图标及导航按钮正常。

发现与此表现吻合的缺陷：实验使用 #form_button_texture * 1 转为 #item_id_aux，但 [JSON UI 类型转换文档](https://wiki.bedrock.dev/json-ui/type-conversion) 已说明新版不再支持 #str * 1 转换。之前的 Node 测试没有运行 Minecraft JSON UI 引擎，不能证明客户端转换有效。

v3.3.4 撤回混合实验。箱子/熔炉表单、ItemStack 图标解析、资源包图标绑定、图标生成器及生成映射全部恢复至用户确认正常的提交 642c0b9。实验源码归档在本地 out/upgrade-audit/failed-hybrid-v3.3.3/，不进入游戏包。

新增回归测试检查全部 1604 个原版物品发送给 ActionForm 的图标均为 textures/...，并检查 ItemStack、排列模板、熔炉和追加背包的数量、耐久文本与槽位映射。

## 修复包验证

1. 导入对应运行环境的 v3.3.4，确认行为包和资源包均为此版本，再退出世界重新进入。
2. 打开同一个物品选择页面，确认木棍、装备、方块和地图恢复显示。
3. 点击一个物品，确认选中内容与图标、名称一致，取消即可。

恢复包使用之前的平面贴图，不启用失败的数字渲染。实际游戏效果尚待反馈。
