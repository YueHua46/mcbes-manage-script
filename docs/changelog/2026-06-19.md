# 更新说明 · 2026-06-19

## 新增悬浮文字系统

新增悬浮文字功能，玩家可以在当前位置上方创建悬浮文字，支持名称、文字内容、缩放、可见距离、背景透明度等基础设置，也可以后续编辑、移动到当前位置或删除。

管理员可在服务器菜单中管理所有人的悬浮文字，普通玩家只能管理自己创建的悬浮文字。

管理员可配置是否对普通成员开放、每个普通玩家最多创建多少个悬浮文字，以及每次创建需要消耗多少金币。创建费用设置为 0 时就是免费，不会扣金币；如果费用大于 0，所有玩家创建时都会按配置扣除金币，管理员也一样。

## 领地边界显示优化

新增领地边界常显开关，玩家可以在领地相关菜单中开启或关闭自己的领地边界显示。

重做领地边界粒子效果，新增角点、边线、地面带、扫描光效等资源，让领地范围更容易看清，也减少旧版粒子不够直观的问题。

优化领地边界相关命令提示，输入命令时说明更完整，减少不知道该填什么参数的情况。

## 修复经济系统相关问题

修复玩家转账写入失败时没有完整回滚的问题，避免出现一边扣钱但另一边没到账的情况。

修复玩家交易市场购买失败、官方商店购买失败、出售物品失败时的回滚逻辑，减少吞物、错价、扣钱不到账等风险。

出售物品时会重新校验计价和数量，避免确认后换物品或数量变化导致结算不准确。

修复公会金库发放不完整时仍按全额扣除的问题，现在发放失败会尽量回滚，避免公会资金异常损失。

## 修复领地与传送安全问题

修复领地创建扣费失败回滚问题，避免创建失败后金币或领地数据状态异常。

修复圈地重叠提示可能泄露其它玩家领地信息的问题，现在普通玩家只会看到必要提示。

优化领地敏感实体放置保护，进一步限制 TNT、末地水晶、凋灵等高风险实体在领地相关场景中的异常使用。

新增统一的安全落点校验，坐标点传送、随机传送、死亡回城等会尽量检查落点是否安全，减少卡进方块、掉落或传送到危险位置的问题。

修复 TPA 目标玩家失效时仍继续执行的问题。

## PVP 修复

修复 PVP 配置边界和夺金统计问题，避免配置值异常导致统计或扣款不准确。

修复 PVP 击杀同时触发普通死亡金币惩罚的问题，现在 PVP 夺金和普通死亡惩罚不会重复叠加。

## 数据与管理工具

数据库 JSON 损坏或解析失败时会保留损坏数据备份，方便后续排查和人工恢复，不再直接丢失现场。

新增 debug 构建入口和相关能力检测封装，便于开发时排查 SAPI 能力、领地粒子和运行环境问题。

服务器实时面板、黑名单管理、官方商店管理等后台工具也做了一些兼容性和提示优化。

## 功能调整

移除举报反馈系统相关入口和服务，避免保留已经不再维护的旧功能。

修复管理员创建悬浮文字时没有按配置扣金币的问题。现在管理员只拥有管理所有悬浮文字和不受数量上限限制的权限，不会绕过创建费用。
