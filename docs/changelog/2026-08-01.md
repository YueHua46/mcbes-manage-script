# 更新说明 · 2026-08-01

## 金币可与原版计分板联动

经济系统现在会自动创建「金币」计分板（`yuehua_money`），并与在线玩家的钱包余额保持一致。菜单内获得、消费或转账金币后，计分板会立即更新；服主通过命令方块或原版计分板指令调整金币时，钱包余额也会同步变化。

这让服主可以按玩家金币数量设置活动门槛、奖励或扣费。例如可用计分板筛选金币达到指定数量的玩家。金币最低为 0，超过原版计分板可记录范围的数值会被限制。

离线玩家仍请使用原有的离线金币管理功能；即使误删金币计分板或某位玩家的分数，玩家钱包中的金币也不会丢失，重新上线后会自动恢复。

## 领地快照权限调整

领地快照的查看、创建、恢复和删除现统一仅限服务器管理员使用，普通领地主和公会管理者将不再看到该入口。

此调整避免高影响的领地回档操作被误用；领地的日常成员、权限和传送点管理不受影响。

操作入口：`领地管理 -> 选择领地 -> 领地快照`（仅管理员可见）。
