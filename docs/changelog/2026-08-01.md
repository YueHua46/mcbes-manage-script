# 更新说明 · 2026-08-01

## 死亡扣款可选择产生负余额

服务器现在可以单独开启「死亡后允许金币扣成负数」。开启后，非 PVP 死亡会完整扣除管理员设置的死亡罚金，即使玩家当前金币不足，余额也会继续降为负数；之后获得的金币会先抵消负余额。

该选项默认关闭，现有服务器会继续保持原来的规则：死亡罚金最多扣到 0。它只影响死亡惩罚，商店购买、玩家转账和其他普通消费仍然要求余额充足。关闭该选项后，已有负余额会归零，不会保留隐藏债务。

设置入口：`服务器设置 -> 经济系统管理 -> 经济系统功能设置`。

## 金币可与原版计分板联动

经济系统会自动创建「金币」计分板（`yuehua_money`），并与在线玩家的钱包余额保持一致。菜单内获得、消费或转账金币后，计分板会立即更新；服主通过命令方块或原版计分板指令调整金币时，钱包余额也会同步变化。

服主可以用原版选择器按金币范围设置活动门槛、奖励或扣费。默认金币范围为 `0～2147483647`；开启死亡负余额后，下限扩展为原版计分板整数下限 `-2147483648`。

离线玩家仍请使用原有的离线金币管理功能；即使误删金币计分板或某位玩家的分数，玩家钱包中的金币也不会丢失，重新上线后会自动恢复。

## 领地快照权限调整

领地快照的查看、创建、恢复和删除现统一仅限服务器管理员使用，普通领地主和公会管理者将不再看到该入口。

此调整避免高影响的领地回档操作被误用；领地的日常成员、权限和传送点管理不受影响。

操作入口：`领地管理 -> 选择领地 -> 领地快照`（仅管理员可见）。
