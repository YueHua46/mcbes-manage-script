# 更新说明 · 2026-07-22

## Backrooms 独立附加包

Backrooms Level 0 的脚本、方块、实体、贴图、雾、灯光和声音已迁移到独立行为包与资源包。苦力怕菜单不再加载该玩法，也不再在自定义维度菜单中预置 `backrooms`；新的进入与救援命令分别为 `/yuehua:backrooms_tp` 和 `/yuehua:backrooms_exit`。

独立包沿用 `yuehua:backrooms` 维度 ID 和原有玩家数据键，升级不会改变已有 manifestation 分配与返回点格式。菜单仅通过通用隔离维度策略阻止聊天、TPA 和坐标点跨越隔离边界。

## 玩家交易市场

经济系统中的原玩家间商品交易功能已统一更名为“玩家交易市场”，菜单、提示和帮助文档不再使用容易引起误解的旧名称。已有上架商品会继续保留。

操作入口：`经济系统 -> 玩家交易市场`。

## 旁观模式菜单稳定性

修复旁观模式通过聊天栏打开苦力怕菜单时可能导致服务器卡死或崩溃的问题。旁观模式下会直接显示提示，不再尝试打开菜单；其他模式从聊天栏打开菜单时，也会降低界面占用期间的重试频率，避免影响服务器运行。
