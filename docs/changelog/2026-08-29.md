# 苦力怕菜单 2026-08-29 更新日志

## 子菜单界面重新设计

苦力怕菜单的所有项目子菜单都换成了统一的“冒险手册”风格。进入公会、经济、领地、传送、管理等功能后，标题、说明文字、图标和操作按钮会使用同一套清晰的目录布局，查找入口更直观。

- 菜单标题区、内容区和关闭按钮重新排版，标题与说明文字的层级更紧凑。
- 每个操作项目使用独立图标、圆头索引条和方向提示，单行与双行说明都保持整齐间距。
- 列表滚动条改为窄边距布局，右侧保留操作安全区，滑动时不再遮挡内容。
- 返回、上一页、下一页等导航按钮使用对应方向图标，减少误操作。

## 消息与设置表单统一

双按钮消息、确认提示和设置表单现在与子菜单使用同一套纸张、页眉和控件样式。下拉框、开关、滑块、输入框和主操作按钮的状态更加容易辨认；其它附加包打开的原版表单仍保持原生样式。

## 任务提示更清晰

任务 HUD 提示改为独立的委托票据样式：任务图标、稀有度颜色、标题和进度信息分区显示。普通、稀有、史诗和传奇任务使用不同的语义颜色，但不会再堆叠多余装饰，信息更容易在游戏中快速阅读。

## 图标与显示细节优化

补充并整理了子菜单、消息、设置和任务提示所需的专用图标与背景素材。同步修正了标题对齐、说明文字位置、列表留白和卡片高度，重载资源包后即可看到完整效果。

## 兼容性

- 主菜单仍使用原有拼图布局。
- 子菜单、消息和设置表单只对苦力怕菜单自己的标记表单生效。
- Minecraft 原版表单、JavaScript REPL 和其它附加包表单不会被新的主题界面接管。
