# 苦力怕菜单 3.3.0 更新日志

## 菜单界面全面更新

主菜单现在使用全新的苦力怕主题界面，将领地、经济、公会、任务、玩家与服务器管理等功能以拼图卡片形式集中展示。菜单按钮增加了与功能对应的专用图标，更容易找到需要的入口。

项目内的子菜单、选项设置表单和双按钮确认提示也已统一为新主题。普通附加包或其它脚本打开的未标记表单仍保持 Minecraft 原生样式，不会被苦力怕菜单的界面覆盖。

## 预设任务系统完整重构

v3.3.0 完整重构了任务系统，新增 **158 条预设任务**，覆盖 Minecraft 主线冒险、世界探索、更新内容体验和 CreeperMenu 功能引导。

### 任务包与章节

预设任务按任务包和章节组织：

- **核心任务包（core）**：生存基础、挖矿进阶、下界探索、末地征程、巅峰挑战
- **世界探索任务包（world）**：生物群系发现、结构探索、成就收集
- **更新内容任务包（updates）**：新版本特性体验、新方块、新生物、新机制引导
- **实验性玩法任务包（experiments）**：需要特定实验性玩法开关的任务
- **CreeperMenu 引导任务包（creeper）**：菜单功能使用教学、领地、经济、公会等系统引导
- **隐藏挑战任务包（hidden）**：达成特定条件后自动完成，提供额外奖励

### 任务稀有度与音效

任务分为四个稀有度等级，完成时播放对应音效：

- **普通（common）**：白色，基础日常任务
- **稀有（rare）**：蓝色，需要一定时间投入
- **史诗（epic）**：紫色，重要里程碑
- **传奇（legendary）**：金色，最高难度挑战，完成时播放特殊音效

### 任务图标与 HUD

- 每个预设任务都配有专属图标（quest-icons-atlas）
- 实时进度 HUD 显示当前任务进度
- 完成提示 Toast 在任务完成时弹出通知
- 主菜单显示待领取奖励数量
- 章节进度显示各章节完成百分比

### 管理员功能

- 三级开关：任务包级、章节级、任务级独立控制
- 预设任务奖励覆盖：不修改结构的情况下调整奖励
- 任务可靠性等级（A/B/C）标注
- 实验性任务包独立管理
- 玩家完成统计和历史挑战查看

### 任务目标扩展

新增支持的任务目标类型：

- 维度切换
- 物品使用
- 方块交互
- 实体交互
- 效果获得
- 方块放置

### 兼容性

- 已有自定义任务继续正常工作
- 玩家已接受和已完成的任务进度完整保留
- 玩家改名后任务进度自动迁移（基于 cmid）
- 任务包版本升级时自动处理定义变化

## 1.26.45 物品图标适配

官方商店、玩家交易市场和背包查看等 Chest UI 已更新原版物品图标映射，新增坐垫、羊毛台阶和白杨木系列等物品的图标路径。

## 悬浮文字系统增强

悬浮文字现在支持更丰富的自定义选项：

- 文字/背景颜色自定义（预设颜色名称和用途模板，精确色值在高级设置中）
- 透明效果控制
- 固定朝向与双面显示设置
- 悬浮文字现在直接绑定到所在维度，避免跨维度显示问题
- 兼容旧版背景透明度数据，编辑时自动转换为完整 RGBA 格式

## 领地飞行安全性改进

领地飞行系统现在能识别远距离传送（如维度切换），并在玩家落点不属于授权领地时立即回收飞行权限。领地探测不再依赖目的地区块加载状态，更加可靠和安全。
