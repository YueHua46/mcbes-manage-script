# 苦力怕菜单 3.3.10 更新日志

## 服务器稳定性与内存占用

本版本针对 BDS 长时间运行时的内存持续增长进行了修复，适合已经出现服务器内存逐步升高、最终掉线或崩服的服主升级。

- 关闭领地系统启动后自动扫描所有领地边界方块的后台预热，改为在实际方块和活塞事件发生时按需读取受影响位置。
- 服务器实体统计改为按需刷新并短时间缓存，避免持续扫描三个维度。
- 降低计分板同步和领地检查任务的后台频率，没有在线玩家时跳过不必要的原生查询。
- 修复玩家断线后继续读取失效玩家对象导致的脚本错误。

## 数据库恢复

- 启动时清理损坏数据库留下的旧分块和损坏备份，避免行为日志的残留数据继续占用世界动态属性。
- 行为日志损坏时仍会先备份原始数据，再使用安全的默认状态恢复服务器启动。

## 升级提示

升级前请完整备份世界。部署后确认服务器实际加载的行为包目录已经替换为本版本；如果服务器仍从旧的 `_mcpack_0` 或其它重复目录加载旧包，修复不会生效。

适配 Minecraft Bedrock **1.26.52** API，适用于 **1.26.5x** 版本族。
