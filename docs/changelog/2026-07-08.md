# 更新说明 · 2026-07-08

## 新增任务系统

主菜单新增「任务系统」入口。玩家可以在这里查看可接任务、已接受任务、当前进度，以及完成后领取奖励。

任务支持一次性、每日、每周和可重复几种类型。服主可以根据服务器玩法发布新手任务、日常任务、周常活动任务或刷怪收集类活动任务。

目前任务目标可统计击杀生物、破坏方块、获得物品和在线时长。奖励可配置物品、金币、经验、完成提示，也支持高级命令奖励。

管理员可在「服务器设置 -> 任务系统」中创建、编辑、启用或停用任务，并设置任务目标、奖励内容和是否让玩家自动接受任务。

## 领地飞行计费调整

领地飞行的扣费规则已调整：当服务器开启「领地飞行绑定经济」并设置了每周期扣费金额后，管理员使用领地飞行也会按相同规则扣除金币。

也就是说，管理员现在只保留管理权限上的便利，例如可以在领地内开启飞行，不受领地信任成员限制；但飞行费用不再免费跳过。

## 对服务器配置的影响

如果「领地飞行绑定经济」关闭，或者「每周期扣除金币」设置为 0，领地飞行仍然是免费使用。

如果「领地飞行绑定经济」开启，但经济系统关闭，所有玩家包括管理员都会无法开启扣费模式下的领地飞行，并会收到提示。服主需要开启经济系统，或者关闭领地飞行绑定经济。

如果玩家或管理员金币不足以支付下一次扣费，领地飞行会自动关闭，并提示补充金币后再开启。

## 使用场景说明

这次调整主要是为了让服务器规则更统一：管理员可以管理和测试功能，但在正式游玩时不会绕过服务器设定的飞行费用。
