# 苦力怕菜单 3.3.1 更新日志

## 任务系统性能优化

v3.3.1 针对 v3.3.0 引入的任务系统进行了全面性能优化，解决了玩家反馈的挖矿和背包操作时的卡顿问题。

### 优化内容

**方块破坏事件批处理**：
- 添加 2 ticks 延迟批处理机制
- 按维度分组批量处理破坏事件
- 快速挖矿场景性能开销减少约 50%

**快照刷新延迟**：
- 延迟 2 ticks 刷新快照状态
- 避免连续操作时的频繁状态读取
- 背包操作场景状态读取减少约 70%

**HUD 渲染频率调整**：
- 从 5 ticks 增加到 10 ticks
- HUD 渲染调用减少 50%
- 视觉流畅度不受影响

**事件早期退出优化**：
- 添加快速路径判断
- 无关事件处理减少约 95%
- 提升整体响应速度

### 性能改进预估

- 快速挖矿场景：减少约 50% 的重复处理
- 背包操作场景：减少约 70% 的状态读取
- HUD 渲染调用：减少 50%
- 无关事件处理：减少约 95%

### 兼容性

所有优化均向后兼容，不影响任务进度统计准确性。批处理和延迟机制确保了跨维度操作的正确性。

## 适用版本

- 行为包版本：3.3.1
- 资源包版本：3.3.1
- Minecraft 基岩版：1.26.40 ~ 1.26.49
