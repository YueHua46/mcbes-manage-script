# 详细更新日志

本目录保存苦力怕菜单与独立 Backrooms 附加包面向服主和玩家的详细更新说明。

- 版本总览与公开入口：[项目更新日志](../../CHANGELOG.md)
- 内容与措辞要求：[更新日志写作规范](STYLE_GUIDE.md)

## 命名规则

- 有明确附加包版本号时使用 `<版本号>.md`，例如 `3.1.14.md`。
- 没有独立版本号的阶段性更新使用 `YYYY-MM-DD.md`。
- 同一个正式版本只保留一份主要版本日志；发布前的阶段记录可以继续按日期归档。

## 内容边界

详细日志用于说明玩家能看到的功能变化、菜单入口、升级要求和重要兼容性风险。实现细节、开发计划与技术设计应放在 `docs/superpowers/` 或对应的专题设计文档中。
