# 苦力怕菜单附加包知识库完整手册

本文档面向安装、配置和使用「苦力怕菜单」附加包的人，用于说明附加包的安装、版本选择、主要功能、菜单路径、常用指令、权限要求与使用教程。本文不是开发文档，可直接作为服务器知识库、群公告、帮助中心或 Wiki 条目使用。

## 1. 附加包简介

「苦力怕菜单」是一个 Minecraft 基岩版服务器功能菜单附加包，基于 Bedrock Script API 制作。它把服务器常见管理功能和便民功能集中到一个菜单道具中，可通过菜单完成传送、领地、坐标点、经济、商店、公会、PVP、统计、留言、服务器设置、功能开关、黑名单、防刷、日志审计等操作。

附加包包含两个核心包：

- 行为包：`苦力怕菜单_BP`，负责脚本、逻辑、指令、数据存储和服务器功能。
- 资源包：`苦力怕菜单_RP`，负责菜单图标、自定义 UI、字体、音效、粒子等资源。

当前行为包与资源包版本为 `2.2.0`，最低引擎版本为 `1.26.0`。实际使用时建议使用与附加包构建版本一致或更高的 Minecraft Bedrock 版本。

## 2. 版本选择

附加包提供不同构建版本。安装前必须先按服务器环境选择正确版本。

### 2.1 普通兼容版

适用环境：

- 本地单人/局域网世界。
- 普通 BDS 服务器。
- Realms 领域服。

特点：

- 可用绝大多数玩家功能与管理功能。
- 不包含 `@minecraft/server-admin` 与 `@minecraft/server-net`。
- 不支持 BDS 专属的进服前黑名单拦截、XUID 网络查询等功能。

适合大多数服务器优先使用。

### 2.2 BDS 增强版

适用环境：

- 仅适用于 Bedrock Dedicated Server，即 BDS 专用服务器。

特点：

- 包含普通兼容版的大多数功能。
- 额外支持 BDS 专属黑名单能力。
- 支持进服前拦截黑名单玩家。
- 支持通过网络能力辅助解析 XUID。
- 不适合 Realms 或普通本地世界。

如果你的服务器必须使用完整黑名单管理和进服前封禁拦截，请使用 BDS 增强版。

### 2.3 本地/BDS 调试版

适用环境：

- 本地测试。
- BDS 调试。

特点：

- 包含 DebugUtilities 调试能力。
- 不适合 Realms。
- 主要用于诊断、测试、渲染调试，不建议正式服务器长期使用。

## 3. 安装教程

### 3.1 本地世界安装

1. 准备普通兼容版 `.mcaddon` 文件。
2. 双击 `.mcaddon` 导入 Minecraft。
3. 进入目标世界设置。
4. 在「资源包」中启用 `苦力怕菜单_RP`。
5. 在「行为包」中启用 `苦力怕菜单_BP`。
6. 确认世界启用了附加包所需的实验性玩法和脚本能力。
7. 进入世界，首次进入会自动获得菜单道具。

### 3.2 Realms 领域服安装

1. 使用普通兼容版。
2. 先在本地世界中启用行为包和资源包。
3. 确认本地世界内附加包运行正常。
4. 将该世界上传到 Realms。
5. 玩家进入领域服后，首次进入会自动获得菜单道具。

注意：Realms 不支持 BDS 增强版所需的 `server-admin`、`server-net` 能力，所以不要给 Realms 安装 BDS 增强版。

### 3.3 BDS 服务器安装

1. 按需求选择普通兼容版或 BDS 增强版。
2. 将行为包放入 BDS 的 `behavior_packs`。
3. 将资源包放入 BDS 的 `resource_packs`。
4. 在世界配置中启用对应行为包和资源包。
5. 如果使用 BDS 增强版，确认服务器版本支持对应的 Script API beta 模块。
6. 启动服务器，观察控制台是否出现「苦力怕菜单 v2.2.0 启动中」和「所有模块已加载成功」之类提示。

### 3.4 管理员权限设置

附加包判断管理员的方式有两种，满足任意一种即可：

- 玩家是服务器操作员。
- 玩家拥有 `admin` 标签。

给自己添加管理员标签可使用：

```mcfunction
/tag @s add admin
```

移除管理员标签可使用：

```mcfunction
/tag @s remove admin
```

建议只给可信任的管理成员添加 `admin` 标签，因为该权限可以访问服务器设置、玩家金币、领地管理、黑名单、背包管理、日志审计等高权限功能。

## 4. 菜单入口与基础使用

### 4.1 如何打开菜单

玩家首次进入服务器时，系统会自动发放 `苦力怕菜单` 道具，物品 ID 为：

```text
yuehua:sm
```

使用方式：

1. 把 `苦力怕菜单` 拿在手上。
2. 对空气或方块使用该物品。
3. 打开主菜单。

如果菜单道具丢失，可以使用以下方式重新获得：

- 在主菜单中点击「给予我苦力怕菜单道具」。
- 输入指令：

```mcfunction
/yuehua:give_me_menu
```

管理员也可以直接给予玩家：

```mcfunction
/give 玩家名 yuehua:sm
```

### 4.2 主菜单功能入口

主菜单通常包含以下入口，部分功能可在设置中关闭：

- 玩家操作：TPA 传送、TPA 设置、假人管理、聊天配置、名字显示设置。
- 坐标点管理：私人坐标点、公共坐标点、坐标点传送。
- 领地管理：申请领地、领地列表、成员管理、权限配置、领地飞行、领地快照。
- 经济系统：钱包、商店、拍卖行、出售物品、转账、红包、财富排行榜。
- 公会：公会列表、创建公会、加入公会、成员、公会金库、公会坐标、公会领地。
- 悬浮文字：创建、编辑、移动、删除悬浮文字。
- PVP 系统：PVP 开关、PVP 统计、PVP 排行榜。
- 数据统计：财富、击杀、死亡、等级、在线时长等排行榜。
- 任务系统：接受任务、查看进度、完成后领取奖励。
- 其他功能：留言板、随机传送、自杀、回死亡点、服务器状态、末影箱查看。
- 获取帮助：圈地教程、菜单丢失处理。
- 服务器设置：仅管理员可见。

## 5. 功能使用教程

## 5.1 TPA 玩家传送

菜单路径：

```text
苦力怕菜单 -> 玩家操作 -> TPA玩家传送
```

功能说明：

- 可请求传送到其他在线玩家身边。
- 可请求其他在线玩家传送到自己身边。
- 对方需要接受请求后才会传送。

使用步骤：

1. 打开「TPA玩家传送」。
2. 选择目标玩家。
3. 选择传送方式：
   - 传送到玩家：你传送到对方身边。
   - 请求玩家传送到你：对方传送到你身边。
4. 等待对方接受。

TPA 勿扰模式：

```text
苦力怕菜单 -> 玩家操作 -> TPA设置
```

开启后，别人向你发送 TPA 请求时不会直接弹窗，而是在聊天栏提示。你可以用以下指令处理：

```mcfunction
/yuehua:tpaccept
/yuehua:tpreject
```

### 5.2 聊天栏配置

菜单路径：

```text
苦力怕菜单 -> 玩家操作 -> 聊天栏配置
```

可用功能：

- 聊天黑名单配置：把指定玩家加入自己的聊天屏蔽列表。
- 静音聊天栏配置：关闭或开启自己的聊天栏接收。

聊天黑名单只影响玩家自己的聊天体验，不等同于服务器封禁。

### 5.3 名字显示设置

菜单路径：

```text
苦力怕菜单 -> 玩家操作 -> 名字显示设置
```

可用功能：

- 设置名字颜色。
- 设置别名。
- 重置显示设置。

说明：

- 服务器设置中可以关闭非管理成员编辑名字显示的权限。
- 管理员始终可以访问该功能。
- 别名长度限制为 20 个字符。

### 5.4 假人模拟玩家

菜单路径：

```text
苦力怕菜单 -> 玩家操作 -> 假人管理
```

功能说明：

假人会在玩家当前位置生成一个模拟玩家。它更接近真实玩家实体，可用于需要玩家在场才能运行的部分原版场景，例如刷怪范围内的农场、机器或长期测试点。

假人不是普通客户端玩家，也不是旧版自定义贴图实体。当前版本的假人使用脚本模拟玩家能力生成，因此不再提供旧版皮肤选择功能。

可用功能：

- 在当前位置创建假人。
- 查看自己的假人列表。
- 重生成假人实体。
- 打开假人背包。
- 管理谁可以查看假人背包。
- 删除自己的假人。

管理员可用功能：

- 查看全服假人。
- 删除任意假人。
- 一键清除全部假人。

可配置项：

- 是否启用假人系统。
- 非管理成员最多可创建多少个假人。
- 创建假人是否消耗金币。

说明：

- 创建者和管理员默认可以打开假人背包。
- 创建者或管理员可以给其他玩家添加背包查看权限。
- 服务器重载或假人死亡后，系统会尝试恢复假人位置和背包。
- 创建费用只在创建时扣除，删除假人不会退回创建费用。

指令方式：

```mcfunction
/yuehua:fakeplayer list
/yuehua:fakeplayer add 假人名称
/yuehua:fakeplayer remove 假人名称
/yuehua:fakeplayer remove_all
```

### 5.5 坐标点系统

菜单路径：

```text
苦力怕菜单 -> 坐标点管理
```

坐标点类型：

- 私人坐标点：只有创建者自己可见和使用。
- 公共坐标点：全服可见，通常需要管理员权限创建。
- 公会坐标点：属于公会，供公会成员使用。

常用操作：

1. 站到需要保存的位置。
2. 打开「坐标点管理」。
3. 点击「添加当前私人坐标点」。
4. 输入坐标点名称。
5. 需要传送时进入「私人坐标点列表」，选择坐标点，点击「传送至此」。

需要管理员权限的操作：

- 查看所有玩家坐标点。
- 搜索某个玩家坐标点。
- 删除玩家坐标点。
- 创建公共坐标点。

指令方式：

```mcfunction
/yuehua:waypoint list
/yuehua:waypoint add 名称 private
/yuehua:waypoint add 名称 public
/yuehua:waypoint tp 名称
/yuehua:waypoint del 名称
```

### 5.6 领地系统

菜单路径：

```text
苦力怕菜单 -> 领地管理
```

领地系统用于保护玩家建筑和资源，防止他人破坏、放置、交互或攻击领地内实体。

#### 5.6.1 如何圈地

1. 手持木棍。
2. 对准地面长按破坏动作，设置领地起始点。
3. 蹲下后对准另一处地面长按破坏动作，设置领地结束点。
4. 打开：

```text
苦力怕菜单 -> 领地管理 -> 领地申请
```

5. 起始点和结束点会自动填入。
6. 输入领地名称。
7. 提交申请。

注意事项：

- 领地大小不能超过服务器设置的最大方块数。
- 每名玩家可拥有的领地数量受服务器设置限制。
- 创建领地通常会按方块数量消耗金币，价格由服务器设置决定。

#### 5.6.2 领地列表与领地详情

菜单路径：

```text
苦力怕菜单 -> 领地管理 -> 领地列表
```

在领地详情中可执行：

- 传送回领地。
- 开关领地边界粒子显示。
- 开启领地飞行。
- 查看或创建领地快照。
- 设置或删除领地传送点。
- 管理领地成员。
- 转让领地。
- 配置公开权限。
- 删除领地。

#### 5.6.3 领地成员管理

领地主可将其他玩家加入领地成员。成员通常可在领地内获得更多权限。

菜单路径：

```text
领地详情 -> 领地成员管理
```

可用操作：

- 添加成员。
- 删除成员。

指令方式：

```mcfunction
/yuehua:land trust 玩家名 领地名称
/yuehua:land untrust 玩家名 领地名称
```

#### 5.6.4 领地公开权限

领地主可配置非成员在领地内是否允许部分行为。常见权限包括破坏、放置、交互等。

建议：

- 公共设施领地可开放交互权限。
- 私人家园建议关闭破坏和放置权限。
- 大型活动场地可按活动需求临时开放。

#### 5.6.5 领地飞行

菜单路径：

```text
领地详情 -> 领地飞行（限时）
```

功能说明：

- 玩家站在有权限的领地内可申请飞行。
- 领主、被信任成员、同公会成员可按权限使用。
- 可设置飞行是否扣金币、扣费间隔、每次扣费金额、离开领地后的宽限时间。
- 如果开启飞行扣费，管理员也会按同样规则扣金币。
- 管理员仍可在领地内使用飞行入口，不受领地信任成员限制，但不会免费跳过费用。

指令方式：

```mcfunction
/yuehua:landflight
```

### 5.7 任务系统

菜单路径：

```text
苦力怕菜单 -> 任务系统
```

功能说明：

任务系统用于给玩家发布日常目标、活动目标或长期目标。玩家可以在任务系统里查看可接任务、已接受任务、任务进度和可领取奖励。

玩家可用功能：

- 查看已发布任务数量、已接受任务数量和可领取奖励数量。
- 接受可接任务。
- 查看任务目标进度。
- 完成任务后领取奖励。

任务类型：

- 一次性任务：完成并领取后通常不再重复。
- 每日任务：按北京时间每天刷新。
- 每周任务：按周刷新。
- 可重复任务：领取后可再次接受。

当前可统计的目标：

- 击杀指定生物或实体。
- 破坏指定方块。
- 获得指定物品。
- 在线时长。

常见奖励：

- 给予物品。
- 增加金币。
- 增加经验。
- 发送完成提示。
- 执行服务器命令。

说明：

- 有些任务可由管理员设置为自动接受，玩家无需手动领取任务也会自动累计进度。
- 完成任务后需要进入任务详情点击「领取奖励」。
- 如果奖励需要背包空间，背包满时可能会把溢出的物品掉落在玩家附近。

### 5.8 经济系统

菜单路径：

```text
苦力怕菜单 -> 经济系统
```

经济系统包含金币钱包、交易记录、商店、拍卖、出售、转账、红包和排行榜。

#### 5.8.1 钱包

菜单路径：

```text
经济系统 -> 钱包
```

显示内容：

- 当前金币余额。
- 今日已获得金币。
- 今日剩余可获得额度。
- 最近交易记录。

指令查询：

```mcfunction
/yuehua:money
/yuehua:money top
```

#### 5.8.2 官方商店

菜单路径：

```text
经济系统 -> 商店
```

可浏览服务器配置的官方商品分类并购买商品。商品由服务器提供，通常用于出售基础材料、特殊物品或服务器道具。

购买步骤：

1. 进入商店。
2. 选择商品类别。
3. 选择商品。
4. 输入购买数量。
5. 确认购买。

#### 5.8.3 拍卖行

菜单路径：

```text
经济系统 -> 拍卖行
```

可用功能：

- 浏览所有商品。
- 查看我的上架商品。
- 上架新商品。
- 购买其他玩家上架的商品。

上架步骤：

1. 点击「上架新商品」。
2. 从背包中选择要上架的物品。
3. 输入价格和数量。
4. 确认上架。

拥有管理权限时，可在必要时修改价格或强制下架并返还卖家。

#### 5.8.4 出售物品

菜单路径：

```text
经济系统 -> 出售物品
```

可用功能：

- 出售单个物品。
- 一键出售所有可出售物品。

说明：

- 只有服务器设置了出售价格的物品才可出售。
- 一键出售会跳过无价格物品。
- 可在管理菜单中维护自定义物品出售价格。

#### 5.8.5 转账

菜单路径：

```text
经济系统 -> 转账
```

指令方式：

```mcfunction
/yuehua:pay 玩家名 金额
```

规则：

- 目标玩家必须在线。
- 金额必须大于 0。
- 不能给自己转账。
- 余额不足时转账失败。

#### 5.8.6 红包

菜单路径：

```text
经济系统 -> 红包
```

红包类型：

- 每人每份固定金额：每份金额相同，总扣款为份数乘以每份金额。
- 拼手气：填写总金币和份数，系统随机拆分。

可用功能：

- 发红包。
- 查看待领红包。
- 查看领取详细。

红包过期时间由服务器设置决定，过期未领取的金额会按规则退回发送者。

### 5.9 公会系统

菜单路径：

```text
苦力怕菜单 -> 公会
```

公会系统适合多人组队、家族、势力、城镇或长期团队玩法。

可用功能：

- 查看公会列表。
- 申请加入公会。
- 处理公会邀请。
- 创建公会。
- 查看我的公会。
- 查看公会信息与公告。
- 查看成员列表。
- 使用公会坐标。
- 查看公会领地。
- 查看公会历史。
- 使用公会金库。
- 领取公会每日红包。
- 退出公会。

会长/副会长可用功能：

- 邀请玩家。
- 审核加入申请。
- 编辑公告。
- 管理成员。
- 晋升或降级成员。
- 踢出成员。
- 转让会长。
- 解散公会。
- 管理公会金库。
- 添加公会坐标。
- 新建或绑定公会领地。

创建公会说明：

- 创建公会需要输入公会名称和公会标签。

公会金库：

- 成员可向金库存入金币。
- 会长可从金库取出金币。
- 可设置副会长是否允许取款。
- 公会领地或公会坐标可配置为从金库扣费。

公会坐标：

- 公会成员可创建和传送到公会坐标。
- 数量上限由服务器设置决定。

公会领地：

- 公会可拥有公会领地。
- 同公会成员可按领地逻辑获得访问权限。
- 每个公会可绑定的领地数量由服务器设置决定。

## 7. 一键功能说明

### 7.1 一键挖矿

功能开关：

```text
服务器设置 -> 功能开关管理 -> 一键挖矿
```

使用方式：

- 使用对应等级的镐子挖矿。
- 系统会根据工具等级、矿物类型和领地权限连锁处理矿石。

支持矿物包括煤、铜、铁、金、青金石、红石、钻石、绿宝石、下界石英、远古残骸等。钻石镐和下界合金镐可配置是否连锁黑曜石和哭泣黑曜石。

### 7.2 一键砍树

功能开关：

```text
服务器设置 -> 功能开关管理 -> 一键砍树
```

使用方式：

1. 手持斧头。
2. 蹲下。
3. 破坏树干。
4. 系统自动处理同一棵树的原木和部分树叶。

说明：

- 会检查是否真的是树，避免误破坏建筑中的原木。
- 会消耗斧头耐久。
- 会遵守领地权限。

### 7.3 下蹲连锁收割作物

功能开关：

```text
服务器设置 -> 功能开关管理 -> 连锁收割作物
```

使用方式：

- 蹲下收割成熟作物。
- 系统会连锁处理附近同类成熟作物。
- 会遵守领地权限。

### 7.4 下蹲一键连锁播种

功能开关：

```text
服务器设置 -> 功能开关管理 -> 连锁播种
```

使用方式：

- 手持种子。
- 蹲下对可种植位置使用。
- 系统会在可种植区域连续播种，直到种子不足或无可种位置。

## 9. 主要设置项解释

以下设置可通过「服务器设置」菜单修改，部分也可用 `/yuehua:setting` 指令修改。

### 9.1 基础模块开关

- `player`：玩家功能模块总开关。
- `land`：领地系统总开关。
- `wayPoint`：坐标点系统总开关。
- `economy`：经济系统总开关。
- `other`：其他功能总开关。
- `help`：帮助菜单开关。
- `sm`：苦力怕菜单入口开关。
- `setting`：系统设置入口开关。
- `guild`：公会系统总开关。
- `floatingText`：悬浮文字系统总开关。
- `fakePlayer`：假人系统总开关。
- `pvp`：PVP 系统入口总开关。
- `stats`：数据统计入口开关。

说明：任务系统入口固定显示在主菜单中；玩家是否有任务可做，取决于管理员是否已经发布并启用任务。

### 9.2 领地相关

- `maxLandPerPlayer`：每名玩家最多可创建的个人领地数量，默认 `5`。
- `maxLandBlocks`：单块领地最大方块数，默认 `30000`。
- `land1BlockPerPrice`：每个领地方块价格，默认 `2`。
- `landSnapshotMaxChunks`：单次领地快照最多处理区块数，默认 `10`。
- `landSnapshotAutoEnabled`：是否启用自动快照。
- `landSnapshotAutoIntervalMinutes`：自动快照间隔分钟数，默认 `360`。
- `landSnapshotAutoMaxPerLand`：每块领地最多保留自动快照数量，默认 `3`。
- `landSnapshotAutoIncludeEntities`：自动快照是否包含实体。

### 9.3 经济相关

- `startingGold`：新玩家初始金币，默认 `500`。
- `daily_gold_limit`：每日可获得金币上限，默认 `100000`。
- `monsterKillGoldReward`：杀怪金币奖励开关。
- `deathGoldPenaltyEnabled`：死亡扣金币开关。
- `deathGoldPenaltyAmount`：死亡扣除金币数量，默认 `100`。
- `redPacketExpiryHours`：红包有效时长，默认 `24` 小时。

### 9.4 公会相关

- `guildCreateCost`：创建公会费用，默认 `100000`。
- `guildMaxMembers`：公会最大成员数，默认 `50`。
- `guildTagMaxLen`：公会标签最大长度，默认 `6`。
- `guildNameMaxLen`：公会名称最大长度，默认 `16`。
- `guildInviteExpireSec`：公会邀请有效期秒数，默认 `86400`。
- `guildShowTagInChat`：聊天中显示公会标签。
- `guildShowTagInName`：名称标签中显示公会标签。
- `guildLeaveOnBlacklist`：封禁玩家时是否处理公会关系。
- `guildBankOfficerWithdraw`：副会长是否可从金库取款。
- `guildMaxLandsPerGuild`：每个公会最多领地数，默认 `5`。
- `guildMaxWaypointsPerGuild`：每个公会最多坐标数，默认 `20`。
- `guildCreateMinOnlineHours`：创建公会所需累计在线小时数，默认 `0`。

### 9.5 PVP 相关

- `pvpMode`：PVP 模式，支持 `vanilla`、`plugin`、`forced`、`off`。
- `pvpSeizeAmount`：PVP 击杀固定夺取金币数，默认 `100`。
- `pvpMinProtection`：PVP 最低金币保护，默认 `100`。
- `pvpToggleCooldown`：玩家切换 PVP 冷却秒数，默认 `30`。
- `pvpCombatTagDuration`：战斗标签持续秒数，默认 `30`。
- `pvpForcedIgnoreLandProtection`：强制大乱斗是否无视领地保护。

### 9.6 行为日志相关

- `behaviorLogEnabled`：玩家行为日志总开关。
- `behaviorLogMaxEntries`：最大日志保留条数，默认 `20000`。
- `itemWatchSnapshotMaxEntries`：物品监控背包快照最大保留条数，默认 `500`，最高 `5000`。
- `behaviorLogLocationIntervalSec`：玩家坐标采样间隔秒数，默认 `60`。
- `behaviorLogInspectorRadius`：日志查询器点击方块时的查询半径，默认 `3`。
- `logPlayerJoin`：记录玩家进入。
- `logPlayerLeave`：记录玩家离开。
- `logPlayerChat`：记录聊天。
- `logPlayerDeath`：记录死亡。
- `logPvpHit`：记录 PVP 命中。
- `logOpenChest`：记录打开箱子。
- `logOpenBarrel`：记录打开木桶。
- `logOpenShulker`：记录打开潜影盒。
- `logItemWatchSnapshot`：记录被监控物品相关背包快照。

### 9.7 防刷相关

- `antiDupeEnabled`：防刷物品总开关。
- `antiDupeBundleRestrictEnabled`：收纳袋防刷子项。
- `antiDupeTrustedPlacers`：防刷白名单玩家名 JSON 数组。

### 9.8 领地飞行相关

- `landFlightEnabled`：领地内飞行总开关。
- `landFlightUseEconomy`：飞行是否按周期扣金币。
- `landFlightBillingIntervalSec`：扣费间隔秒数，默认 `60`。
- `landFlightGoldPerInterval`：每个周期扣除金币，默认 `0`。
- `landFlightLeaveGraceSec`：离开领地后的飞行宽限秒数，默认 `5`。

说明：开启飞行扣费后，管理员也会按配置扣金币。管理员只是不受领地信任成员限制，不会绕过飞行费用。

### 9.9 假人与悬浮文字

- `fakePlayerMaxPerPlayer`：非管理成员最多可创建假人数量，默认 `3`。
- `fakePlayerCreateCost`：创建假人消耗金币，默认 `0`。
- `floatingTextAllowMembers`：是否允许非管理成员创建悬浮文字。
- `floatingTextMaxPerPlayer`：非管理成员最多悬浮文字数量，默认 `3`。
- `floatingTextCreateCost`：创建悬浮文字消耗金币，默认 `0`。

## 10. 推荐初始化流程

新服务器首次安装后，建议按以下顺序配置：

1. 确认行为包和资源包都已启用。
2. 进入服务器，给主要管理账号添加管理员权限：

```mcfunction
/tag @s add admin
```

3. 打开苦力怕菜单，进入「服务器设置」。
4. 在「通用系统设置」中设置服务器名称、欢迎语、随机传送范围。
5. 在「功能开关管理」中关闭暂不开放的模块。
6. 在「经济系统管理」中设置初始金币、每日上限、死亡扣费、商店和出售价格。
7. 在「领地系统管理」中设置领地数量、大小和价格。
8. 在「公会系统管理」中设置创建费用、成员上限和公会标签显示。
9. 在「防刷物品设置」中确认防刷总开关开启。
10. 在「玩家行为日志」中确认需要记录的行为类型。
11. 在「进服弹窗公告」中配置服务器规则和新人提示。
12. 使用非管理权限账号测试菜单、传送、领地、经济、聊天和权限。

## 12. 常见问题

### 12.1 为什么我没有菜单道具？

可能原因：

- 你不是首次进入，之前拿到后丢弃了。
- 行为包未正确加载。
- 菜单道具入口已被关闭。

处理方式：

```mcfunction
/yuehua:give_me_menu
```

如果仍失败，请联系管理员检查行为包是否启用。

### 12.2 为什么我看不到某个菜单入口？

可能原因：

- 该功能已被关闭。
- 该入口仅管理员可见。
- 当前版本不支持该功能。
- 当前平台不支持 BDS 专属能力。

### 12.3 为什么黑名单管理不可用？

黑名单进服前拦截依赖 BDS 增强版。普通兼容版为了适配本地世界、普通 BDS 和 Realms，不包含 `server-admin` 与 `server-net`，因此无法提供完整黑名单功能。

### 12.4 为什么不能创建领地？

可能原因：

- 未用木棍正确设置两个圈地点。
- 领地超过最大方块数。
- 已达到个人领地数量上限。
- 金币不足。
- 与其他领地冲突。
- 当前维度或位置不允许圈地。

### 12.5 为什么无法传送到坐标点？

可能原因：

- 坐标点已被删除。
- 目标维度不可用。
- 目标位置不安全。
- 服务器关闭了坐标点系统。

### 12.6 为什么一键砍树或一键挖矿没生效？

可能原因：

- 对应功能已被关闭。
- 没有使用正确工具。
- 一键砍树需要蹲下并手持斧头。
- 连锁播种和连锁收割需要蹲下。
- 所在位置受领地保护限制。

### 12.7 为什么红包、商店、拍卖行或出售物品不可用？

可能原因：

- 经济系统被关闭。
- 服务器尚未配置商店商品。
- 该物品没有出售价格。
- 玩家余额不足。
- 背包空间不足。

### 12.8 为什么领地飞行会突然关闭？

可能原因：

- 离开了有权限的领地。
- 宽限时间结束。
- 金币不足以支付周期扣费。
- 领地飞行已被关闭。
- 服务器重载或玩家重新进入后状态被刷新。

### 12.9 为什么假人没有生成或不见了？

可能原因：

- 假人系统被关闭。
- 已达到普通玩家假人数量上限。
- 金币不足以支付创建费用。
- 当前位置或区块不适合生成模拟玩家。
- 服务器重载后假人正在等待自愈恢复。
- 当前运行环境的模拟玩家能力不可用或行为异常。

处理建议：

- 确认「假人系统」已开启。
- 管理员可查看全服假人列表并尝试重新生成。
- 创建失败时一般不会消耗费用，若已扣费但生成失败，系统会尝试退款。

### 12.10 为什么任务没有进度或不能领取奖励？

可能原因：

- 任务尚未发布或未启用。
- 你还没有接受该任务，且该任务没有设置为自动接受。
- 当前行为不符合任务目标，例如生物、方块、物品或维度不匹配。
- 任务已经完成但尚未进入任务详情点击「领取奖励」。
- 背包空间不足，导致物品奖励无法正常进入背包。

处理建议：

- 打开「任务系统」查看已接受任务和可接任务。
- 按任务详情中的目标说明完成对应行为。
- 完成后进入任务详情点击「领取奖励」。
- 如果确认条件正确但仍无进度，请联系管理员检查任务配置。

### 12.11 为什么进服欢迎弹窗没有显示？

可能原因：

- 没有启用公告。
- 公告被停用。
- 当前 UI 正忙或被其他界面占用。
- 行为包未正确加载。

## 13. 管理注意事项

- 不要随意给非管理成员 `admin` 标签。
- 修改经济、领地、公会和黑名单前，建议先在测试服验证。
- 使用 BDS 增强版前确认服务器支持对应 Script API beta 模块。
- 黑名单、背包管理、金币管理、强制解散公会都属于高权限操作，应保留管理记录。
- 开放公共领地权限前，确认不会被恶意破坏。
- 开放悬浮文字和假人前，建议设置数量上限和金币成本。
- 行为日志保留条数不要设置过小，否则排查问题时可能缺少记录。
- 如果服务器玩家较多，自动快照、物品监控、位置快照等功能应谨慎开启并控制频率。

## 14. 快速排查清单

当附加包异常时，可按以下顺序检查：

1. 行为包和资源包是否都启用。
2. 安装版本是否与服务器环境匹配。
3. Minecraft/BDS 版本是否达到最低引擎版本。
4. Script API beta 模块是否可用。
5. 控制台是否显示附加包初始化成功。
6. 玩家是否拥有正确权限或 `admin` 标签。
7. 功能是否在「功能开关管理」中被关闭。
8. 相关配置是否填写为合法数字或布尔值。
9. Realms 是否误装了 BDS 增强版。
10. BDS 专属功能是否在普通兼容版中被误用。
