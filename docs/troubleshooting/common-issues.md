# 常见问题

## 应该下载哪个版本？

无法确认时选择普通兼容版。只有明确运行 BDS，且需要进服前黑名单拦截、XUID 或 HTTP 能力时，才选择 BDS 增强版。

## 更新后仍显示旧资源包

确认实际部署目录中的文件已替换，检查行为包与资源包 manifest 版本，并完整重启服务器。客户端仍缓存旧资源时，再清理对应缓存后重新进入。

## `/reload` 后新功能没有出现

自定义维度、脚本模块和资源包升级可能需要完整重启，`/reload` 不能替代服务器或世界重启。

## Realms 中部分功能不可用

Realms 使用普通兼容版，不支持 `@minecraft/server-admin` 和 `@minecraft/server-net` 提供的 BDS 专属能力。

## 如何提交有效 Bug

提供苦力怕菜单版本、Minecraft 精确版本、运行环境、构建变体、其他 Addon、复现步骤、预期与实际结果、日志和截图。
