# Backrooms Atmosphere Remaster Design

## Goal

将 `backrooms` 自定义维度从“全局明亮的黄色空间”重制为由实体荧光灯实际塑造明暗的 Level 0：绝大部分常规空间可见，但灯带覆盖存在确定性规律与局部缺口；墙纸、地毯、天花板共享暖黄色环境色调，同时保持三种材质的视觉和触感差异。

## Binding visual direction

- 统一色调：所有表面都受到旧式暖黄荧光灯影响，不出现当前截图中的中性白天花板、纯白灯板或灰褐地毯。
- 墙纸：旧黄绿色，明度高于地毯，带极淡、低对比的老式壁纸纹样和少量污渍；不能退化为纯色墙。
- 地毯：更深的米褐黄色，低对比、低频起伏，不呈现清晰织物纤维或密集像素噪点。
- 天花板：泛黄的灰米色吸音板，哑光、细颗粒；必须与墙纸和地毯可明显区分。
- 灯管：暖象牙白发光中心，不能接近纯白；死灯保留同材质但明显变暗。
- 雾仅负责远距离吞没和综合色调，不从相机起点开始抬亮暗处。近处无灯空间必须能够真正变暗。

## Lighting topology

- 灯具继续使用 2 格长商业荧光灯形态，但位置不再是房间内完全随机散点。
- 每个普通房间先根据房间长轴建立一条或多条规则灯带；同一条灯带中的灯具等距排列，并允许确定性缺灯。
- 常规房间绝大多数可走面积应落在灯光覆盖内；边缘走廊、转角、门后和少量异常区域允许落入阴影。
- 普通区域允许少量整条灯带缺失或局部断灯；blackout 区域仍以黑暗为主。
- 所有选择必须由世界种子和区域坐标确定，同一区域重启后结果不变。

## Audio

- 后室环境音保持在 `ambient` 类别，核心是稳定、低音量的荧光灯电流与房间底噪，不作为旋律 BGM。
- 移除当前明显的 2.85 kHz/4.72 kHz 尖锐音；2 kHz 以上功率比例应显著降低。
- 嗡鸣片段不得重叠播放；重播周期不得短于音频时长。
- 电流浪涌更安静、更少见，空间异常音继续稀疏出现。
- 进入后室时停止当前原版音乐，并用零音量循环 music track 占用音乐通道；离开后解除该 track。欢迎音乐代码不属于本次修改范围。
- 脚步使用原创的干燥/潮湿 × 行走/奔跑四类声组，每类至少三个变体；由接地状态、水平位移累计和采样速度驱动，不能使用每秒随机抽样模拟步态。
- 行走声应厚闷、低调，奔跑声更重、更急；潮湿地毯增加压水与鞋底黏离感，但不得像踩水坑一样夸张。

## Canon baseline

- 建筑、灯光、声音和后续实体系统以 Kane Pixels 影像体系为主要参考。
- Wikidot Level 0 仅用于补充“来源不明的低语、熟悉人声与墙后抓挠”等相容氛围，不用其“未确认实体”条目否定 Kane Pixels Lifeform。

## Movement

- 普通地毯摩擦为 `0.65`，提供稳定但不过度迟滞的脚感。
- 潮湿地毯摩擦为 `0.72`，比普通地毯更慢、更黏。
- 不给玩家添加速度或缓慢状态效果，避免和其他系统产生状态冲突。

## Compatibility and constraints

- 保留资源包 `"capabilities": ["pbr"]`，不得删除或改名。
- 不修改 Backrooms 的确定性房间拓扑、生成事务、manifestation 隔离或安全传送逻辑。
- 新资源必须放在项目内，能进入 standard 与 BDS 构建产物。
- 贴图保持 64×64 PNG；声音保持原创并更新生成脚本与 attribution。

## Verification

- 自动测试验证灯具形成规则灯带、仍存在确定性缺口，并且灯不落入墙体。
- 自动测试验证地毯摩擦精确值、灯光强度和 PBR capability 未变。
- 自动测试验证嗡鸣重播周期不短于素材时长、音乐锁生命周期、声音文件存在且格式有效。
- 像素统计验证四类表面均为暖黄色域，同时墙纸、地毯和天花板的均值、局部对比和高频能量彼此有可测差异。
- TypeScript、Backrooms 专项测试、资源包构建全部通过。
