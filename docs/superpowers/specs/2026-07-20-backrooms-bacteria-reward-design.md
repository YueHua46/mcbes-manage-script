# Backrooms 细菌实体属性与奖励设计

## 目标

将 Kane Pixels 风格的 `yuehua:backrooms_lifeform` 定位为稀有小 Boss，并采用玩家社区广泛使用的 Bacteria 名称。

## 最终规则

- 中文显示名：`细菌（Bacteria）`。
- 英文显示名：`Bacteria`。
- 最大与初始生命值：`500`。
- 追踪距离：`512` 格；生成后立即获取最近玩家，并持续锁定到目标死亡或实体死亡。
- 锁定目标存活期间不会因失去视线、寻路失败或追逐超时而换人；目标死亡、离线或离开后室时才交接给最近的可用玩家，暂无可用目标时保持随机游走。
- 取消受击硬直并将击退抗性设为满值；攻击时持续贴近目标，缩短前摇并同步攻击动画与命中时点，避免奔跑玩家无限风筝。
- 生成时从实体位置播放高音量咆哮；存活期间每 `8～16` 秒播放一次咆哮或叫声，空间传播范围为 `72` 格。
- 服务器控制台记录生成结果、坐标、锁敌确认、交接与结束状态；带有 `yuehua.backrooms_lifeform_debug` 标签的测试玩家同时接收游戏内调试消息。
- 击杀经验：固定 `50` XP，通过 `minecraft:experience_reward` 由实体死亡时生成原版经验球。
- 独立附加包不读写苦力怕菜单或其它附加包的金币数据，击杀奖励仅保留原版 `50` XP。

## 实现边界

实体属性由 `behavior_packs/Backrooms/entities/backrooms_lifeform.json` 管理；Backrooms 行为包和资源包可以脱离苦力怕菜单独立安装。自定义实体翻译键从完整 `yuehua:` type ID 解析，避免被误当作 `minecraft:` 实体。

## 验证

测试必须覆盖准确名称、500 生命、512 格独立目标范围、无脚本硬直、50 XP 原版掉落、菜单经济表无后室条目及自定义实体本地化键。完成后运行全部 Backrooms 测试、TypeScript、ESLint 与 JSON 校验。
